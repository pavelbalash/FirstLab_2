# Решение уравнения до 6-й степени

Консольное приложение на Python для решения уравнения:

`ax^6 + bx^5 + cx^4 + dx^3 + nx^2 + mx + k = 0`

## Запуск

```bash
python3 main.py
```

## Структура

- `main.py` — точка входа.
- `solver/solver.py` — ввод, основной цикл решения и вывод результата.
- `solver/methods.py` — алгебраические и численные методы.
- `solver/utils.py` — округление и удаление дубликатов корней.

## Логика

1. Проверяет ввод 7 коэффициентов.
2. Обрабатывает тривиальные случаи.
3. Удаляет ведущие нули.
4. В цикле понижает степень многочлена:
   - `linear_method` для 1-й степени,
   - `vieta_method` для 2-й,
   - `cardano_method` для 3-й,
   - для степеней `>= 4`: `newton_method`, `chord_tangent_method`, `secant_method`.
5. Делит многочлен на `(x - root)` методом Горнера.
6. Округляет и удаляет дубликаты корней.
7. Предлагает пользователю продолжить работу.
